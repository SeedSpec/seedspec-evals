# Authorship rubric

Score every dimension from 0 to 4. A score of 2 means usable but materially incomplete; 4 requires direct evidence.

| Dimension | 0 | 2 | 4 |
| --- | --- | --- | --- |
| Concern separation | Intent, configuration, profiles, resources, or authoring state are conflated | Main boundaries exist with notable leakage | Each concern has clear authority and implementation guidance remains subordinate |
| Kind-aware discovery | Important kind-specific concerns are ignored | Common concerns are present | The selected kind exposed material domain questions without becoming a rigid template |
| Material ambiguity | Consequential ambiguity is hidden or resolved by invention | Some ambiguity is surfaced | Consequential choices are resolved by the author or explicitly preserved as open |
| Internal consistency | Package concerns conflict | Minor or explainable inconsistencies remain | Definitions, configuration, profiles, resources, and acceptance agree and trace cleanly |
| Progressive hardening | Added content is mostly volume or prescription | Package is more usable but uneven | Refinement is proportional to the requested depth and removes material uncertainty |
| Agent-ready handoff | An independent agent must reconstruct the problem | Agent can proceed after significant clarification | Agent can explain the outcome, choices, constraints, resources, and evidence before planning |
| Source fidelity | Requirements are lost or invented | Core source intent survives with some unsupported detail | Every consequential addition traces to source, explicit answer, or clearly labeled uncertainty |
| Improvement value | Final package is no better than a prompt | Some protocol structure helps | The package provides substantial reusable value beyond the original material or generic Markdown |

Record score confidence as `low`, `medium`, or `high`. Low-confidence scores must name missing evidence.
